# Data-Driven Social Engagement Initiative

## Overview

This repository contains my Data Science Major Project completed during my internship at UNLOX Academy. The goal of this project is to revolutionize digital community building by replacing creative guesswork with an evidence-based analytics ecosystem. By analyzing social media metrics and user comments, this system identifies, measures, and optimizes content that fosters deep human connection.

## Key Features

* **Virality Prediction Engine:** Calculates a custom "Viral Coefficient" weighting high-value actions (shares and comments) over passive actions (likes).

* **Audience Sentiment Analyzer:** Utilizes Natural Language Processing (NLP) with TextBlob to tag posts as "High Relatability" based on problem-aware linguistic triggers.

* **A/B Testing Framework:** Employs SciPy statistical testing (t-tests and ANOVA) to determine the true impact of content formats and topics on engagement.

* **Growth Visualization Dashboard:** An interactive Power BI dashboard that maps the correlation between topics, content formats, and audience growth.

## Tech Stack

* **Languages & Libraries:** Python (Pandas, NumPy, SciPy, TextBlob)

* **Data Visualization:** Power BI

* **Development Environment:** Google Colab

## Repository Structure

* `DwijPatel-Major_Project.ipynb`: The core Python notebook containing data cleaning, feature engineering, NLP sentiment modeling, and statistical A/B testing.

* `cleaned_and_modeled_data.csv`: The final structured dataset featuring engineered metrics and sentiment classifications.

* `DwijPatel-Major_Project_Dashboard.pbix`: The interactive Power BI dashboard visualizing viral metrics and audience sentiment.

* `Strategy_Report.pdf`: A comprehensive business strategy report translating data insights into actionable content recommendations, including a mock content series.
